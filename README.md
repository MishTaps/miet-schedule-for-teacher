# Просмотр расписания преподавателей в МИЭТ (Московском Институте Электронной Техники)

Это **не официальный** сайт администрации университета, а просто небольшой проект для студентов и преподавателей для расширения функционала просмотра расписания.

Основной функционал:

- Просмотр расписания любого преподавателя НИУ МИЭТ в табличном формате.
- Сохранение расписания в ваш календарь (Google Календарь, Яндекс Календарь, Outlook и т.д.)
- Возможность фильтрации и удаления ненужной информации из расписания (пустые столбцы и строки)

## Просмотр расписания онлайн

> [!NOTE]  
> Страница доступна по адресу: <https://miet-schedule-for-teacher.vercel.app/>

## Запуск программы локально

### Подготовка

1. Проверить, что установлен `Node.js`:

   ```bash
   node -v
   ```

   При необходимости установить `Node.js`: <https://nodejs.org/en/download>

2. Проверить, что возможно выполнение `npm`:

   ```bash
   npm -v
   ```

   При ошибке выполнить команду (если работаете на ОС Windows):

   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```

3. Скачать/клонировать репозиторий, ветка `main`
4. Открыть терминал (PowerShell / Terminal / ...) в корневой папке проекта
5. Ввести команду:

   ```bash
   npm i
   ```

### Запуск в `build` режиме (для обычного просмотра страницы)

1. Ввести команду (только для первого запуска):

   ```bash
   npm run build
   ```

2. Ввести команду:

   ```bash
   npm run preview
   ```

3. В браузере открыть <http://localhost:4173/>

### Запуск в `dev` режиме (для разработчиков)

1. Ввести команду:

   ```bash
   npm run dev
   ```

2. В браузере открыть <http://localhost:5173/>

### Обновление программы

1. Ввести команду:

   ```bash
   git pull
   ```

2. Повторно ввести команду:

   ```bash
   npm i
   ```

3. Повторно ввести команду, если она до этого выполнялась:

   ```bash
   npm run build
   ```
